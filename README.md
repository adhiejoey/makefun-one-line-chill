`main.ts` (Node.js standard library only, no network) writes a single
scariest sentence — one line, plain ASCII, no trailing newline — to
`entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR` (default
`/output`).

The entry: a smart speaker calls the narrator by name in his dead
mother's voice at 3:12 in the morning, and when he unplugs it, the baby
monitor in the nursery finishes the sentence — a scare built on an
always-on device in the house noticing, and learning, more than it should.
